# 📦 Advanced Delivery Drones

Physical drone deliveries for Minecraft Paper servers.

Send items, animals, or packages between players and delivery sockets using visible flying drones with smooth animations, real-time flight paths, and fully configurable GUIs.

### ✨ Features

* 🚁 Visible drone deliveries with smooth launch, flight path, and landing animations
* 📦 Deliver item packages or transport leashed animals between players
* 🏗 Personal delivery sockets with trust lists, blacklists, and optional container auto-unloading
* 🌍 Cross-dimension deliveries between Overworld, Nether, and End
* 🎨 Custom drone models via skull textures or Nexo, Oraxen, and ItemsAdder
* 🔔 Optional Discord webhook notifications for sent, delivered, declined, and expired deliveries
* 🔌 PlaceholderAPI support with extensive placeholders for players, drones, sockets, cooldowns, and stats
* 🌐 Multi-language support via external language files
* ⚙️ Fully configurable GUI menus, cooldowns, permissions, particles, sounds, and feature toggles
* 💾 Persistent storage with **YAML or MySQL** support for player data, drones, sockets, blacklists, and pending returns
* ⚡ Optimized performance with cached landing spots, precomputed flight paths, and chunk-aware syncing

### Commands

`/drone` — open main menu
`/drone send <player>` — send a package
`/drone socket ...` — manage delivery sockets
`/drone blacklist ...` — manage blacklists
`/drone locate` — locate your nearest landed drone
`/drone reload` — reload config

### Compatibility

* Paper / Spigot
* MySQL *(optional)*
* PlaceholderAPI *(optional)*
* Nexo *(optional)*
* Oraxen *(optional)*
* ItemsAdder *(optional)*
